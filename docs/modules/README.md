# Module docs — progressive disclosure index

One file per module here, written or refreshed **when that module is actually touched and
verified**, not written speculatively. Root `CLAUDE.md` stays an index; load a module file only
when working inside that module, so a session touching pharmacy never has to load grooming's
context and vice versa.

## Format for a module file
- What it is, in one paragraph
- Current route/controller/service/frontend file locations
- Feature flag name, if dark-launched
- Known gaps or risks specific to this module
- Link to the relevant `backend/scripts/log-memory.js`-logged bugs/lessons if any exist
